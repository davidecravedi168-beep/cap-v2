# AI Office — static GitHub Pages build

Dashboard statica per un ufficio generale di agenti AI: orchestratore, specialisti, revisori, memoria e approval desk.

## Pubblicazione su GitHub Pages

Carica `index.html`, `styles.css` e `app.js` nella root del repository, poi attiva GitHub Pages da `Settings → Pages → Deploy from branch`.

Il sito non contiene chiavi API e non esegue pagamenti, cancellazioni o azioni esterne: il pulsante di approvazione è una simulazione dell’approval gate per validare l’esperienza utente.
